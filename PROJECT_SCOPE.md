# FoodLoop – Project Scope

## 1. Project Introduction

FoodLoop is a web-based surplus food redistribution platform that connects food donors with NGOs and volunteers. The main purpose is to reduce food wastage by helping surplus food reach people in need.

## 2. Scope of the Project

The project includes the development of a full-stack web application with four types of users: Donor, NGO, Volunteer and Admin.

## 3. Features Included

### 3.1 User Authentication
- User registration and login.
- Secure password storage.
- Role-based access for Donor, NGO, Volunteer and Admin.

### 3.2 Donor Module
- Donors can create food donation listings.
- Donors can enter food name, quantity, description, pickup location and expiry time.
- Donors can view their donation listings.
- Donors can edit or delete their listings.
- Donors can accept or reject NGO requests.

### 3.3 NGO Module
- NGOs can register and log in.
- NGOs can browse available food donations.
- NGOs can request food donations.
- NGOs can track their donation requests.
- Only verified NGOs can request donations.

### 3.4 Volunteer Module
- Volunteers can view assigned pickups.
- Volunteers can view pickup and delivery details.
- Volunteers can update collection and delivery status.

### 3.5 Admin Module
- Admin can view registered users.
- Admin can verify NGO accounts.
- Admin can manage user accounts.
- Admin can monitor food donations.
- Admin can view donation reports.

### 3.6 Food Management
- The system displays available food donations.
- Expired listings are marked as expired and cannot be requested.
- Invalid food quantities are rejected.
- Donation status is updated throughout the process.

## 4. Features Not Included

The following features are outside the scope of the initial version:

- Online payment and money transfers.
- GPS-based live volunteer tracking.
- Mobile application for Android and iOS.
- Automatic food quality testing using AI.
- Integration with external food delivery companies.
- Advanced AI-based food demand prediction.

## 5. Expected Users

1. Food Donors – Restaurants, hotels, colleges and event organisers.
2. NGOs – Organisations that distribute food to people in need.
3. Volunteers – People who collect and deliver donated food.
4. Admin – Person responsible for managing the platform.

## 6. Expected Outcome

The final outcome will be a working web application that allows donors to publish surplus food, NGOs to request donations, volunteers to manage pickups and administrators to monitor the system.

FoodLoop aims to reduce avoidable food wastage and improve food redistribution through a centralised digital platform.
